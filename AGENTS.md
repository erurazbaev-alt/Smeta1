# Правила работы над проектом

- Работать только в этой папке и перед изменениями сначала читать текущие файлы.
- Делать только ту функцию, которую просит пользователь, и не ломать уже работающие функции.
- Использовать только обычные HTML, CSS и JavaScript — без npm, фреймворков и внешних ресурсов.
- Все данные пользователя должны оставаться в браузере. Ничего не отправлять в интернет.
- Делать интерфейс удобным: использовать понятные подписи; поля и кнопки должны быть не меньше 44 px; обеспечить работу с клавиатуры и на телефоне.
- Показывать деньги с пробелами между тысячами, например `15 000 ₸`.
- Пустые и неверные числа считать нулём. Никогда не показывать `NaN`.
- Не запускать Git и ничего не публиковать без прямой просьбы пользователя.
- После работы перечислять изменённые файлы и объяснять, как проверить результат.
