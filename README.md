# Смета за 5 минут

«Смета за 5 минут» — простое веб-приложение для быстрого составления сметы или коммерческого предложения и сохранения результата в PDF.

Приложение предназначено для предпринимателей, которым нужно подготовить коммерческое предложение клиенту, и офисных сотрудников, составляющих смету закупки или расходы для руководителя.

## Файлы приложения

- `index.html` — структура страницы, поля, таблица позиций и кнопки.
- `styles.css` — внешний вид и адаптация интерфейса для компьютеров и телефонов.
- `script.js` — расчёты, работа с данными пользователя и сохранение документа в PDF.

## Как открыть

Дважды щёлкните по файлу `index.html`. Приложение откроется в браузере.

## Как проверить

Добавьте две позиции:

1. Количество — `2`, цена — `15 000`.
2. Количество — `1`, цена — `8 000`.

Итог должен быть: **38 000 ₸**.
